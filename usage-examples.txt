### Core Authentication Functions

The `src/lib/dal.ts` file contains the following key functions:

1.  **`getSecret()`**: This function retrieves the secret key used for HMAC signature generation and verification. In a production environment, it expects the `PRFC_PORTAL_SECRET` environment variable to be set, falling back to a development-only secret in non-production environments.

2.  **`validateToken(token: string, secret: string): Session | null`**: This function is responsible for parsing and validating an authentication token. It verifies the HMAC signature, checks the token's expiry, and extracts the `ownerid` and `isAdmin` status.
    *   **File:** `src/lib/dal.ts`
    *   **Lines:** 24-42

3.  **`verifySession(): Promise<Session>`**: This function attempts to verify the user's session by checking for the `prfc_auth` cookie. If the cookie is missing or the token is invalid/expired, it throws an `AppError` with an "UNAUTHORIZED" status.
    *   **File:** `src/lib/dal.ts`
    *   **Lines:** 47-59

4.  **`getSession(): Promise<Session | null>`**: Similar to `verifySession`, but it returns `null` if no valid session is found instead of throwing an error. This allows for conditional rendering based on the user's authentication status.
    *   **File:** `src/lib/dal.ts`
    *   **Lines:** 61-69

5.  **`requireAdmin(): Promise<Session>`**: This function first verifies the session using `verifySession()` and then checks if the authenticated user has administrative privileges. If not, it throws a `FORBIDDEN` error.
    *   **File:** `src/lib/dal.ts`
    *   **Lines:** 71-78

6.  **`generateToken(ownerid: number, isAdmin: boolean): string`**: This function generates a new authentication token for a given `ownerid` and `isAdmin` status, using the HMAC-SHA256 algorithm with the secret key.

1.  **User Authentication (e.g., login):** This would involve a third-party service or database lookup to establish the user's identity. Upon successful authentication, a session object containing `ownerid` and `isAdmin` information is created.
